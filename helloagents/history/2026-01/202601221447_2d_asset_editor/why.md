# 变更提案: 2D素材编辑器（头身选择拼装 + 作为底图进入生成）

## 需求背景
当前 2D 素材生成主要依赖用户在对话框中输入 prompt，由系统自动分析并匹配头/身素材再生成图片。该流程缺少“像游戏创建角色一样”的可视化素材选择能力，导致：
1. 用户无法精确选择某个头部表情素材与某个身体动作素材进行拼装；
2. prompt 中对表情/动作的描述存在歧义，匹配结果不稳定，反复试错成本高；
3. 用户希望先确定“底图角色”（表情+动作），再继续进行配件/背景等生成链路。

## 产品分析

### 目标用户与场景
- **用户群体:** 使用 2D 素材生成的创作者/运营同学/产品同学
- **使用场景:** 在 2D 素材生成 Tab 下快速创建“可控的角色底图”，再输入 prompt 生成带配件/背景的最终图
- **核心痛点:** 不能可视化选择素材；动作/表情不稳定；缺少底图复用机制

### 价值主张与成功指标
- **价值主张:** 提供可视化 2D 角色创建能力（表情+动作），提升可控性与效率
- **成功指标:**
  - 用户可在 1 次以内确定满意的底图并进入后续生成
  - 2D 底图复用链路可稳定完成生成（不重新匹配头/身、不重复拼装）

### 人文关怀
本功能不引入额外个人隐私数据采集；在 UI 提示中清晰告知“底图已锁定动作表情”，减少误解与挫败感。

## 变更内容
1. 在“2D素材生成”Tab 下的对话框中，于“场景”按钮右侧新增按钮“2D素材生成”，点击打开 2D 素材编辑器弹窗。
2. 弹窗左侧提供素材选择能力：
   - “表情”：按视角展示 `data/2d/{frontview|upview}/head` 素材，按文件名排序、无默认选中。
   - “动作”：二级选择（站立/动感/跳跃/跑动/坐姿），统一映射到动作类型（站姿/欢快/跳跃/跑动/坐姿），并按视角展示对应身体目录 `data/2d/{frontview|upview}/body_{stand|happy|jump|run|sit}`。
3. 用户同时选择表情与动作后，“生成”按钮激活；点击“生成”调用 `per-data-2D.py` 完成拼装，使用其返回的白底 `1024x1200` 图片作为预览/底图。
4. 生成结果下方提供“重试/使用”：
   - “重试”：清空已生成结果并清空已选（回到素材选择）。
   - “使用”：将底图添加到输入框上方预览条（仅保留 1 张，支持清除/替换；切换 2D/3D 或切换视角自动清空）。
5. 用户输入 prompt 并点击生成后，继续走原有分析预览与生成流程（审核/解析/大模型生成等）；当底图存在且 prompt 中包含表情/动作描述时，提示“底图已锁定动作表情，仅处理配件/背景”，并在后端跳过“匹配头/身 + step1 拼装”，直接进入配件/背景/Gate 等后续步骤。

## 影响范围
- **模块:** frontend、backend、2D 生成链路
- **文件:** `frontend/src/components/*`、`frontend/next.config.js`、`app_new.py`、`generation_controller_2d.py`
- **API:** 新增 2D 素材列表/拼装接口；`/api/start_generate` 增加可选字段以承载底图
- **数据:** 不新增持久化数据；底图输出复用现有 `output/` 目录

## 核心场景

### 需求: 打开 2D 素材编辑器
**模块:** frontend
在 2D 模式下，用户可从对话框中进入 2D 素材编辑器弹窗。

#### 场景: 从对话框入口打开
用户处于“2D素材生成”Tab，点击“场景”右侧的“2D素材生成”按钮
- 弹出 2D 素材编辑器弹窗

### 需求: 按视角选择表情与动作素材
**模块:** frontend/backend
素材列表需随“视角（正视角/仰视角）”切换，并按文件名排序。

#### 场景: 切换视角刷新素材
用户切换视角（正视角/仰视角）
- 弹窗素材目录随之切换，且当前底图预览条自动清空

### 需求: 生成拼装预览
**模块:** backend/frontend
用户选择表情与动作后点击“生成”，在弹窗右侧展示拼装结果。

#### 场景: 调用拼装接口并展示
用户完成表情与动作选择后点击“生成”
- 调用拼装逻辑并返回白底 1024x1200 图片
- 在弹窗右侧展示拼装结果，并出现“重试/使用”

### 需求: 使用底图进入生成链路
**模块:** frontend/backend
用户点击“使用”后，将底图带入后续生成链路，并跳过头/身匹配与拼装步骤。

#### 场景: prompt 继续生成（锁定动作表情）
用户输入 prompt 并点击生成，且 prompt 中包含表情/动作描述
- 前端提示“底图已锁定动作表情，仅处理配件/背景”
- 后端跳过“匹配头/身 + step1 拼装”，直接从底图进入配件/背景/Gate 等步骤

## 风险评估
- **风险:** 新增静态资源与目录列表接口可能带来路径穿越/越权访问风险
- **缓解:** 后端对可访问目录与文件扩展名做白名单校验；所有路径做规范化并拒绝 `..`；仅允许访问 `data/2d/**` 与 `output/**`
