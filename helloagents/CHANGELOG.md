# Changelog

本文件记录项目所有重要变更。
格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [Unreleased]

### 新增
- 生成流程输入框上方新增运行日志条，展示后端任务最新日志以提示后台仍在运行
- `GET /api/job/<job_id>/status` 新增返回字段 `latest_log` / `logs_count`
- 2D 素材编辑器：支持选择表情/动作素材并拼装为白底 `1024x1200` 底图，作为后续 2D 生成链路输入（支持跳过 step1）

### 变更
- 运行日志条文本改为单行跑马灯滚动展示最新任务日志
- 任务结束（成功/失败/取消）后运行日志条延迟 1 秒自动隐藏
- JOY 3D 编辑器弹窗比例调整为 1:1，并以高度为基准自适配不同屏幕尺寸
- 2D 素材编辑器拼装结果预览背景调整为黑色
- 2D 素材编辑器表情/身体素材缩略图预览背景调整为黑色
- 2D 素材编辑器表情素材缩略图改为完整预览（不裁切）
- 2D 素材编辑器“拼装结果”展示透底 `2000x2000`，点击“使用”透传白底 `1024x1200` 作为后续底图

### 修复
- 运行日志条位置调整为挂载在 ChatInput 卡片容器上方
- 修复批量更新 `timeout` 时注释位置不当导致的多处语法错误（`matchers/*`、`utils/*`、`generation_controller*` 等）
- 修复打开/关闭 3D 编辑器导致对话历史（生成记录）被清空的问题
- 修复 3D 编辑器 iframe 内 canvas 被拉伸显示：改为按 `1024x1200` 比例等比缩放并居中适配
- 修复 3D 编辑器 toolbar/approved-row 固定尺寸导致小屏挤压画布：改为 `clamp()` 响应式缩放并允许横向滚动
- 修复 3D 编辑器高清渲染过程导致画布可视尺寸跳变：仅调整渲染 buffer，不更新样式尺寸
- 修复 `npm -C frontend run export:unix` 在当前运行环境下因跨目录 `rename` 报 `EXDEV` 导致的静态导出失败（改为预加载补丁将 `rename` 降级为 copy+unlink）
